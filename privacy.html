Privacy Policy

Last updated: November 10, 2026

Slat Team Util ("the bot") is a private Discord bot used internally by Slat's video editing team. This policy explains what data it accesses and how that data is used.

Google data accessed

Access to Google data is optional and is granted by a team administrator signing in with a Google account. The bot requests read-only scopes only:

  • Google Drive (drive.metadata.readonly): the names, IDs, and creation dates of folders inside the project folder the administrator chooses. The bot does not open or download file contents.
  • YouTube (youtube.readonly): the connected channel's name and its latest uploads (titles, privacy status, and scheduled or published times).

The bot cannot create, change, move, share, or delete anything in Google Drive or YouTube.

How the data is used

Folder names and dates are used to register new projects in the team's project list. Video titles and times are used to fill in posting schedules for the team's projects. The data is shown only inside the team's own Discord server.

Storage

The bot stores the project information it creates and the Google access token for each connection in its own database, which runs on a computer or server operated by the team, and in the team's private backups. Tokens are never shown in Discord or written to the audit history.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train AI models. It is not transferred to anyone outside the team. The bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Discord data

Inside Discord, the bot stores the user IDs and server display names of team members involved in projects, along with the project records administrators enter (names, links, prices, schedules).

Removing access and data

An administrator can disconnect Google Drive or YouTube at any time with the bot's Disconnect button, which also revokes the access at Google. Access can also be removed at myaccount.google.com/permissions. Server administrators can erase all of the bot's data for their server with its reset command.

Contact

For questions about this policy, open an issue at github.com/lucasdonini0/slat-bot-site/issues.
